# 人工智能科普课程与互动实验室

东华大学 · 东华大学附属松江高级中学 合作项目

## 启动

本项目基于 Base44 平台构建，使用 React + Tailwind CSS + Vite。

```bash
npm install
npm run dev
```

开发服务器启动后，前台地址为 `/`，管理后台地址为 `/admin`。

## 管理入口与初始化管理员

- 管理后台路径：`/admin`
- 管理后台要求登录且账户角色为 `admin`。
- **管理员由平台设置初始化，不允许"第一个注册者自动成为管理员"。**
- 初始化管理员：在 Base44 控制台 → App Users 中邀请用户并设置角色为 `admin`。
- 普通用户（role=user）访问 `/admin` 会看到"无管理权限"提示。
- 学生无注册入口，不登录即可浏览所有公开页面与运行实验。

## 安装/批准依赖

当前所有依赖已随项目安装。摄像头手势实验使用 MediaPipe Hand Landmarker，通过 CDN 动态加载（见 `src/experiments/gesture/GestureLab.jsx` 中的 `RESOURCE_CONFIG`）。正式国内部署前需将模型与 WASM 资源自托管，替换 CDN 地址。
