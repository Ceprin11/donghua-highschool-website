# 学生账号、资料与作业

## 使用方法

管理员登录 `/admin/login`，进入“学生账号”。可以上传 `.xlsx`、UTF-8 的 `.txt`，也可以粘贴姓名，用中文逗号、英文逗号或换行分隔。Excel 读取第一张工作表的第一列，表头“姓名”可选，后台提供模板，每次最多 500 人。

预览时生成小写姓名拼音账号，重复时依次加 2、3 等数字。多音字可以在预览表中修正。确认导入后可以下载本次账号 CSV，Excel 可直接打开。初始密码等于账号名。重复导入同一姓名会新建带数字的账号，不会覆盖原账号或重置原密码。

学生从网站右上角“学生登录”进入，或访问 `/student/login`。第一次登录必须改密，8 至 128 个字符，不能与账号或当前密码相同。登录保留 7 天。右上角显示姓名，个人页面 `/student/account` 可改密或退出。没有公开注册功能。

管理员可按姓名或账号搜索学生、停用和启用账号、重置密码。重置密码会恢复为账号名，撤销旧会话，并要求下次登录改密。停用后旧登录立即失效，重新启用不会自动恢复会话。

在“资料下载”后台新建标题、说明和附件，保存草稿后点击发布。学生在 `/downloads` 查看已发布资料。在“课程作业”后台填写作业要求并添加附件，保存后发布，学生在 `/assignments` 查看和提交。所有学生看到相同内容。后台编辑已发布内容时，学生继续看到发布版本，直到管理员再次发布。

学生每次提交一个文件，可以重新提交。老师在作业列表点击“查看提交”，看到所有学生的姓名、账号、最新提交时间和文件，未提交者也在列表中。不提供评分和评语。

支持 PDF、DOC、DOCX、PPT、PPTX、PNG、JPG。老师上传的资料与作业附件每个最大 500 MiB，作业正文图片和学生提交每个最大 50 MiB。每条资料或作业最多 10 个管理员附件。PDF 和图片可打开查看，Office 文件下载后用本地软件打开。上传进度和错误显示在文件选择区域，上传后仍需保存草稿并发布。

## 数据和权限

作业正文以网页图文展示。管理员可添加文字段落、PNG/JPG 图片及说明，调整顺序或删除，发布前可预览。每条正文最多 40 段，总文字最多 20000 字，图片说明最多 300 字。学生端图片按可用宽度等比例显示，保留文字换行。附件是可选补充，不代替正文。图片与附件都遵循草稿、发布和下架权限。

`003_students_learning.sql` 随服务启动自动应用。学生、学生会话、资料和作业、文件清单、提交记录分别保存在 `students`、`student_sessions`、`learning_items`、`learning_files`、`homework_submissions`。

学生密码使用异步 scrypt 和随机盐派生，不保存明文。管理员与学生使用独立 Cookie，可以在同一浏览器分别登录。学生写操作检查 Origin 和学生 CSRF token。首次改密要求、停用状态、资料发布状态以及作业归属由服务端检查。学生不能调用管理员接口，不能访问他人作业。

文件上传时写入私有的 `DATA_DIR/uploads`，校验后移到 `DATA_DIR/media/learning-<随机id>.<扩展名>`，不把整个大文件放进应用内存。完成或校验失败后清理临时文件。文件不进入 public 或 dist，文件名不会直接成为公开地址。附件只通过 `/api/student/files/:id` 或管理员文件接口读取，响应禁止缓存。下架的资料和作业不再允许学生获取附件。后台内容 JSON 导出不包含学生个人资料和作业。

既有备份与恢复命令已包含学生表和私有文件。恢复后撤销管理员及学生会话。备份应在停服维护窗口执行。不要将数据库、备份、账号 CSV 上传到公开仓库。

## 已知限制

- Excel 支持 `.xlsx`，旧 `.xls` 请另存为 `.xlsx`。
- 拼音不能自动确定所有姓名读音，导入预览允许修正。
- 重提后学生和老师的提交列表显示最新文件，旧文件仍在私有存储中；草稿中移除的附件也保留。当前没有永久清理界面。
- Word 和 PPT 暂不在网页内转换预览，使用下载后打开。
- 现有腾讯云审核地址使用 HTTP。正式启用真实学生账号和作业前需要完成 HTTPS 配置，避免密码和文件通过明文连接传输。

## 验证

新增 API 测试使用临时数据库覆盖名单解析、重名编号、重复账号冲突、首次改密、学生与管理员权限隔离、附件下架、他人作业访问、重新提交、重置及停用、备份恢复。

浏览器测试 `tests/browser/students.spec.js` 通过真实页面完成管理员导入、发布资料和作业，学生首次改密、下载、提交，老师查看文件，并检查 1440、1024、768、360 像素视口。
