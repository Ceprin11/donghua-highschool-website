## 姿势训练

界面参考 Teachable Machine 官方姿势项目的灰色背景、白色类别卡、训练区、预览区、蓝色操作按钮和高级设置。主站保留白、黑、橙视觉风格。

实际计算复用官方 Community Pose 0.8.6 训练类，使用 PoseNet 2.2.1 与 TensorFlow.js 1.3.1。骨架来自实际人体关键点，分类头从 PoseNet 热图和偏移特征学习。默认 50 轮、批量 16、学习率 0.0001，已对照官方高级设置。

支持类别增删与改名、上传人物图片、单张和按住采样、训练与停止、重新训练、摄像头或新图片预测。修改样本或类别会使旧结果失效。导出产生 pose-model.json、pose-model.weights.bin 和 metadata.json。主站嵌入页允许下载这些文件。

示例取自 TensorFlow 官方深蹲视频。加载时实际检测 40 帧，并根据膝关节角度选取两类各 12 帧。旧 MobileNet 图像模型、咖啡和橙子样本及旧适配源码移到私有归档。
