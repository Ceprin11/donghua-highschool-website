# 首页视觉样板

2026-09-23 完成。参考 Backend.AI 首页的白底、黑色大标题、橙色操作按钮、宽留白与滚动入场，使用本项目课程内容和实验可视化。

## 本版内容

- 重做首页，统一公开网站导航、页脚、基础字体与配色。
- 首屏复用现有 NeuralEngine 进行训练，展示权重、分类边界、损失与测试准确率。支持圆环和交叉数据、暂停、继续和重置。
- 预览最多训练 640 步。离开可视区域或隐藏网页时暂停计算。系统选择减少动态效果时不自动训练，仍可手动开始。
- 四个课程主题采用展开式介绍，图示按主题 slug 匹配。实验入口改为整行布局。
- 首页按发布内容展示教师、作品和活动；没有内容时收起对应区块。后台设置的首页图片、介绍、教学特点和栏目可见性继续生效。
- “中文简化版神经网络训练场”改为“神经网络训练”，“像素与图像处理实验室”改为“像素与图像处理”。清理实验里的开发说明，保留算法含义、操作提示和数据使用说明。
- 同步种子文案和本地数据库中的原始默认措辞。只替换匹配的旧文案，保留其他内容和草稿。修改前的相关记录在 `_project_review/20260923-ui-refresh/copy-before.json`。
