## 保留页面

修改前保存了首页、实验目录、神经网络、迷宫、后台的桌面及手机截图和原 22 项浏览器回归结果。它们保存在同一私有目录的 baseline 文件中。两个保留实验没有改写计算引擎。本轮再次通过分类/回归切换、特征选择、训练、挑战重置、迷宫策略与课堂模式的测试。

## 适配差异

- CNN 保留原运算布局和颜色。主要控件与运算面板中文化，矩阵增加点击等价操作。窄屏保留至少 1050px 的图形宽度，在实验内平移。关闭面板时释放其定时器，多次切图的张量数不增加。
- TensorSpace 采用 Apache-2.0 仓库内的两个具体示例。没有取得指定 tensorspace.org 中文站点的独立页面源码，因此未声称该网站的外壳和全部控件都已逐项复现。手写示例保留原三维场景；训练示例原来自动训练、控制台输出，本地增加可见控制和指标。
- Transformer 保留 GPT-2 small、63 个原始模型分片和词元原文。20 页交互讲解已中文化，标题字体本地化。手机顶栏与采样控件允许换行，说明卡片改为底部面板并可滚动，桌面仍可拖动和缩放。分片流式装入一个缓冲区，ONNX 在 Worker 中运行，关闭图优化和预打包以降低初始化内存。模型权重没有替换。修复 Svelte 订阅读取旧句子的问题。
- 图像训练按类别、训练、预览三栏实现，使用 Community 中的可训练类。它是课程改编工作区，Google 官网完整前端没有公开移植。
- 原作者、论文与源码链接保留。自动跨站统计、视频嵌入与运行 CDN 已移除。

## 未验证与已知差异

指定在线演示站未完成逐状态现场对照录像。现有 CNN 名为 original 的早期截图被后续脚本覆盖，不能用作未经适配的原站证据。原代码与模型是对照基础，不能把本地截图说成在线原站截图。

CNN 和 Transformer 的长篇原论文说明及部分深层术语仍为英文。Transformer 核心 20 页交互讲解、输入和采样操作已有中文。没有逐层取得上游参考数值文件；CNN 已做选定中间值重算，其余模型确认真实计算和结果联动，尚不构成所有中间张量的跨环境数值一致性证明。

设备验收使用桌面 Chrome 模拟触屏和视口。真实手机、平板 GPU、浏览器全屏权限和真实摄像头仍需设备验证。Transformer 中文输入效果未专项评估，中文界面不代表模型对中文做过优化。
