# 互动实验算法说明

实验目录包含六个可运行实验。神经网络与奖励迷宫沿用项目算法，四个上游实验使用取得的上游源码和模型。来源、版本和构建方法见 [UPSTREAM_LABS](UPSTREAM_LABS.md)。

## 配置契约

共享配置位于 `shared/experiment-config.js`。后端预设和前端实验调用同一份校验规则。`validateConfig(engine, value, { partial })` 校验字段和取值，`mergeConfig` 按代码默认值、数据库默认配置、挑战配置、当前操作的顺序合并。数组与地图整体替换。

| 引擎 | 支持的主要字段 |
| --- | --- |
| neural | 分类或回归；分类数据集 `blobs`、`cluster`、`circle`、`xor`、`spiral`；回归数据集 `reg-plane`、`reg-gauss`；0 至 6 个隐藏层，每层 1 至 8 个节点；输入特征、激活函数、L1/L2 正则化、学习率、噪声、测试比例、批量、样本数与随机种子 |
| maze | A/B 地图或 2 至 12 行列的自定义地图；学习率、折扣、探索率、目标奖励、陷阱惩罚、每步代价、回合步数、随机种子与速度 |
| cv、cnn、lenet、teachable、transformer | 后台配置为空对象。CV 是目录；四个上游实验在各自界面中操作，后台维护观察任务与小测 |

运行入口和配置能力由 `shared/lab-registry.js` 固定。旧图像处理、温度抽样和手势实验已归档，不属于当前配置契约。

## 神经网络训练

`NeuralEngine.js` 实现浏览器端 MLP。数据生成与切分使用种子随机数，训练函数只读取训练集。分类使用 Sigmoid 输出与二元交叉熵，回归使用线性输出与 MSE。隐藏层支持 Tanh、ReLU、Sigmoid 和 Linear。反向传播按批次累积并平均梯度。

画布上的点、预测区域、网络结构、训练损失、测试损失与评估指标都来自同一个 `NeuralNet` 实例。暂停取消下一帧，切换数据或网络结构会停止旧循环并重建数据与模型。学习率和批量大小在运行中从最新配置读取。`numericalGradientCheck` 用有限差分检查反向传播。

回归支持平面与多峰高斯数据，连续预测值用于画布着色，RMSE 用于评估误差。输入特征、正则化、节点热力图和权重交互见 [神经网络工作台](NEURAL_PLAYGROUND.md)。

## CNN 与 LeNet

CNN Explainer 加载上游原模型，按实际输入计算卷积、激活、池化和分类结果。网络节点与详情视图使用同一次前向计算的数据。TensorSpace 手写页将画布输入交给 LeNet，预测和三维中间层使用同一份输入。

CNN 训练板块已下架。旧地址跳转到手写数字与三维网络。

## 姿势采样与训练

使用 Teachable Machine Community 的 Pose 0.8.6 训练类、PoseNet 2.2.1 和 TensorFlow.js 1.3.1。PoseNet 从画面计算人体关键点，以及供分类头训练的热图与偏移特征。用户可以建立类别，上传人物图片或采集相机样本，再训练分类头。默认学习率 0.0001、50 轮、批量 16，与官方姿势页面一致。类别和样本变化使旧预测失效，需要重新训练。模型可导出为 JSON、权重和类别信息三个文件。

示例来自 TensorFlow 官方深蹲视频，抽取 40 帧并实际计算关键点，按膝关节角度选择 12 个站立样本和 12 个下蹲样本。骨架和概率由模型计算。示例用于演示操作，不用于评价跨人物准确率。样本留在浏览器会话中。

## Transformer

使用 Transformer Explainer 的 GPT-2 ONNX 模型与本地分词器。输入词元、Embedding、Attention、中间值及候选分布来自模型或上游提供的演示缓存。输入自定义文本会触发真实推理，Top-k、Top-p 与温度控制采样。分片流式写入预分配内存，推理完成后释放输入输出张量。

## 奖励迷宫

`MazeAgent` 使用 Q-learning。动作先经过边界和障碍筛选，再用于行为选择和下一状态更新。目标和陷阱是终止状态，只使用即时奖励。非终止状态如果没有合法下一动作，也只使用即时奖励。达到最大步数会结束回合。

可达性搜索遵循同一套环境规则，不能把必须穿过陷阱的地图当作可达。编辑器只允许一个起点和一个终点。改地图、奖励参数或清空学习会停止旧定时器，清理策略路线和回合记录，再建立新的 Q 表。策略试走来自当前 Q 表。奖励曲线按实际回合奖励范围缩放。
