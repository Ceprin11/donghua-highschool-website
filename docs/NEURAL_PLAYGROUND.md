# 神经网络工作台

2026-09-23 更新。参考 TensorFlow Playground 的分类与回归实验布局和交互设计，使用本项目的独立计算引擎，保留中文课程、挑战案例、课堂小测和演示模式。

## 操作

- 顶部提供分类与回归任务切换，以及重置、训练与暂停、单步训练、学习率、激活函数、正则化和正则化强度。
- 分类数据包括圆环、交叉、两团点和螺旋。回归数据包括平面和多峰曲面，可调训练集比例、噪声和批大小，也可重新生成数据。两个任务分别记住所选数据集，切换任务停止并重建模型。
- 输入支持 X₁、X₂、X₁²、X₂²、X₁X₂、sin(X₁)、sin(X₂)，至少保留一个特征。
- 网络支持 0 至 6 个隐藏层，每层 1 至 8 个神经元。每个节点显示该神经元在二维输入空间上的输出。
- 悬停节点可放大查看，点击后固定查看。连线颜色表示权重正负，粗细表示绝对值；悬停显示数值，点击可暂停并编辑权重。
- 输出显示训练和测试损失曲线及热力图。分类显示准确率和预测概率，并可离散化；回归显示连续预测值和 RMSE。两种任务均可显示测试数据。
- 手机按数据、网络、输出排列。超出可用宽度的网络图支持横向滚动。

## 计算

使用真实反向传播和小批量梯度下降。隐藏层激活函数支持 Tanh、ReLU、Sigmoid 和 Linear，分类输出使用 Sigmoid 与二元交叉熵，回归输出使用线性函数与均方误差 MSE。回归的 RMSE 单独计算，不含正则化惩罚。L1 惩罚为强度乘以权重绝对值之和，L2 惩罚为强度乘以权重平方和的一半，偏置不参与正则化。显示损失包含正则化惩罚。

每一步更新一个批次。轮数按累计读取的训练样本数除以训练集大小计算。数据与网络结构变化后停止训练并清空历史。学习率、批大小和正则化可在当前模型上调整。训练、指标、节点图和分类图使用同一个模型，隐藏网页时暂停训练。

后台默认参数和挑战案例可保存任务类型、回归数据集、激活函数、正则化、输入特征及六层网络。已有配置补齐新增默认参数后继续工作，不修改网站现有发布内容。

## 与参考站的差异

本页实现分类和回归任务，未加入 URL 参数分享。使用本项目的归一化数据，分类采用二元交叉熵，回归采用均方误差，因此损失数值和训练轨迹不与参考站逐值一致。未复制参考站源代码，也不通过 iframe 或外部服务运行实验。

独立的“数据与摄像头说明”页面、路由和页脚入口已移除。手势实验内的摄像头操作提示继续保留。
