## 16 项浏览器验收

1. API、媒体和模型缺失返回 404，环境文件、数据库、历史审计不能下载，WASM MIME 正确。
2. 1440px 宽度五栏目和五实验打开与刷新，无横向溢出。
3. 768px 宽度同样检查。
4. 360px 宽度同样检查。
5. 温度挑战实际改为 1.8，抽样统计可清空，小测不产生写请求。
6. 实验维护、作品不存在和服务失败显示不同状态。
7. 神经网络挑战停止旧训练，控件和隐藏层变化，数据重新生成与演示退出可用；迷宫奖励更新清空学习，策略试走不新增训练回合。
8. 像素挑战改变实际画布，邻域可查看；手机尺寸下替代拖动完成三个物体并能重新挑战。
9. 匿名管理路由要求真实登录，八个管理页面可显示，概览实验数为 5、题目数为 15。
10. 作品真实表单执行私有草稿、预览、发布、编辑保留公开旧版、发布更新和下架。
11. 同一教师表单发布后首页与关于页面同步，隐藏后两处均不显示。
12. 图片真实上传、私有访问限制、来源修改与刷新持久化。
13. 本地 MediaPipe 0.10.32 加载本地模型并对程序视频推理；关闭后 track ended、video.srcObject 清空。
14. 五个实验默认参数表单和挑战表单实际保存、保留旧发布版并再次发布。
15. 固定课程主题编辑发布，新建判断题恰好两项，题目解析再次发布。
16. 主视觉、校徽和活动照片从素材选择器保存；活动图片在首页与关于页展示，活动更新和下架生效。

## 开发期间失败及处理

初期恢复错位源码时遇到 Home/About JSX 语法错误，已修复。首轮浏览器发现嵌套 main，改为单一页面主区域后通过。管理表单核对修复了必填 slug 缺失、题目编辑器缺失、非法实验参数字段，以及已发布内容没有再次发布入口的问题。

扩展后台浏览器检查曾因假定列表排序、隐式标签包含文本和素材按钮重复名称而超时。按记录身份定位、使用独立 label 关联和清晰素材按钮名称后，定向三项与最终完整 16 项都通过。

受限沙箱初次执行测试或 Vite 时发生 spawn EPERM。后续通过该项子进程执行审批完成标准 npm test 和生产构建，没有跳过断言。npm 初次联网受缓存模式限制，显式指定本项目缓存及 offline=false 后安装。

直接 npm ci 曾对 better-sqlite3 13.0.3 的 binding.gyp 启动隐式 node-gyp 编译，因没有 Visual Studio C++ 工具失败。核对官方包确认其包含各平台预编译库后，增加项目级 `.npmrc` 使用这些库。重装、真实 SQLite 测试、启动、生产构建和最终浏览器测试均通过，没有安装或修改全局工具。

安装日志有 ESLint 9 和保留 UI 组件所用 Recharts 2 的上游弃用提示。本轮未把工具升级或未使用组件重构扩展为另一个任务；当前锁定依赖在本项目检查和运行中通过。
